**Network toolbox**

The Ping tab is now **Tools**, with ten network tools in one place:

- **Ping** and **Network scan**: as before, now opened from the grid.
- **Traceroute** (new): every router on the way to a host, with each hop's name and latency.
- **DNS lookup** (new): A, AAAA, CNAME, MX, TXT, NS, SOA and PTR records from the DNS server you choose, with response time.
- **DNS benchmark** (new): ranks your network's DNS against Cloudflare, Google, Quad9, OpenDNS, AdGuard and more, so you can pick the fastest.
- **Port scanner** (new): open ports on any device or server (common ports, 1–1024 or your own list) with the service name.
- **Network info** (new): public IPv4/IPv6, provider and location, local IP, subnet mask, router, DNS, MTU, Private DNS and Wi‑Fi signal. Long-press any value to copy it.
- **Wi‑Fi analyzer** (new): nearby networks on 2.4, 5 and 6 GHz, a channel chart and the least crowded channel. Needs the Location permission, which Android requires to show Wi‑Fi networks; nothing is stored or sent.
- **Wake-on-LAN** (new): turn on a computer on your network; devices are saved for one-tap waking.
- **Whois & IP lookup** (new): registrar, dates and name servers for domains; owner, network range and location for IP addresses.

**Fix:** Cloudflare tests show the provider and data center again. Cloudflare had started refusing the request Pulse used.

**Install:** open Settings → Updates in the app, or download `Pulse-v1.8.0.apk` below.

**ארגז כלים לרשת**

לשונית הפינג הפכה ל**כלים**, עם עשרה כלי רשת במקום אחד:

- **פינג** ו**סריקת רשת**: כמו קודם, עכשיו נפתחים מתוך הרשת.
- **Traceroute** (חדש): כל נתב בדרך אל המארח, עם השם וזמן התגובה של כל תחנה.
- **בדיקת DNS** (חדש): רשומות A,‏ AAAA,‏ CNAME,‏ MX,‏ TXT,‏ NS,‏ SOA ו-PTR משרת ה-DNS שבחרתם, עם זמן תגובה.
- **השוואת שרתי DNS** (חדש): מדרג את ה-DNS של הרשת מול Cloudflare,‏ Google,‏ Quad9,‏ OpenDNS,‏ AdGuard ועוד, כדי לבחור את המהיר ביותר.
- **סורק פורטים** (חדש): פורטים פתוחים בכל מכשיר או שרת (פורטים נפוצים, 1–1024 או רשימה משלכם), עם שם השירות.
- **פרטי הרשת** (חדש): IPv4/IPv6 ציבוריים, ספק ומיקום, IP מקומי, מסכת רשת, נתב, DNS,‏ MTU,‏ DNS פרטי ועוצמת Wi‑Fi. לחיצה ארוכה מעתיקה כל ערך.
- **מנתח Wi‑Fi** (חדש): רשתות סביבכם ב-2.4, 5 ו-6 GHz, גרף ערוצים והערוץ הכי פנוי. דורש הרשאת מיקום, ש-Android מחייבת כדי להציג רשתות Wi‑Fi; שום דבר לא נשמר ולא נשלח.
- **Wake-on-LAN** (חדש): הדלקת מחשב ברשת שלכם; המכשירים נשמרים להדלקה בהקשה אחת.
- **Whois ומיקום IP** (חדש): רשם, תאריכים ושרתי שמות לדומיינים; בעלים, טווח כתובות ומיקום לכתובות IP.

**תיקון:** בדיקות Cloudflare מציגות שוב את הספק ואת מרכז הנתונים. Cloudflare התחילה לסרב לבקשה ש-Pulse השתמשה בה.

**התקנה:** הגדרות ← עדכונים באפליקציה, או הורדת `Pulse-v1.8.0.apk` מלמטה.
