# Pulse Speed v1.5.1 — Universal Multiplatform Release & Bug Fixes

## 🚀 What's New & Highlights

This release resolves the issues reported in v1.5.0, fully stabilizes the LG webOS and Windows desktop experiences, and expands Pulse to **11 platforms** including Smart TVs, Media Centers, Desktop, Mobile, and CLI!

---

### 🛠️ Critical Fixes

1. **LG webOS TV IPK Fix (`-5: IPK Extraction Failure` resolved)**
   - **Root Cause:** In the previous build, `splashBackground` was specified as a hex color string (`#0E1514`) instead of a file path, causing webOS Luna package installer to fail with `-5: IPK Extraction Failure`.
   - **Fix:** Switched to the official LG WebOS packaging pipeline (`@webos-tools/cli` `ares-package 3.2.6`), configured `"bgColor": "#0E1514"` and validated package integrity. Tested and verified for LG webOS 3.0 through webOS 24+.

2. **Windows Desktop App Fix (Blank screen resolved)**
   - **Root Cause:** The old Windows launcher used the legacy Internet Explorer / Trident WinForms control, which does not support modern ES6+ JavaScript (`async/await`, `fetch`, arrow functions), resulting in a blank window.
   - **Fix:** Re-engineered `Pulse.exe` to serve the modern responsive UI over an embedded in-memory HTTP server and launch Microsoft Edge / Google Chrome in standalone application window mode (`--app=`). Integrated client-side heartbeat keep-alive to automatically close the server when the user closes the window.

### 🌐 Universal Multiplatform Support (11 Deliverables)

- 📱 **Android & Android TV / Fire TV:** `Pulse-v1.5.1.apk` (Supports phones, tablets, and Leanback TV launcher).
- 📺 **LG webOS Smart TV:** `Pulse-v1.5.1-webos.ipk` (Built with official `ares-package` for LG webOS CLI / Device Manager / Homebrew).
- 📺 **Samsung Smart TV (Tizen):** `Pulse-v1.5.1-tizen.wgt` (Tizen widget with remote control key handling).
- 🎬 **Stremio Addon:** `Pulse-v1.5.1-stremio-addon.zip` (Community addon with manifest, stream meta, and web player).
- 📦 **Kodi Media Center:** `Pulse-v1.5.1-kodi-addon.zip` (`plugin.program.pulsespeed` for Kodi 19/20/21 Matrix, Nexus, Omega).
- 🖥️ **Windows Desktop:** `Pulse.exe` and `Pulse-v1.5.1-windows.zip` (Portable executable, zero installer required).
- 🍎 **macOS Desktop:** `Pulse-v1.5.1-mac.zip` (Standalone `Pulse.app`).
- 🐧 **Linux Debian / Ubuntu / Raspberry Pi:** `pulse_1.5.1_all.deb` (Debian package with desktop menu entry).
- 🐧 **Linux Universal Tarball:** `Pulse-v1.5.1-linux.tar.gz`.
- 💻 **Universal Terminal CLI:** `pulse-cli.py` (Zero-dependency Python speed test tool with Bufferbloat analysis).
- 🌐 **Web Standalone:** `Pulse-v1.5.1-web.zip` (Static web speed test player for self-hosting).

### ✨ Core Features Added

- **Bufferbloat & Loaded Latency Analysis:** Real-time loaded ping probing during download and upload tests with letter grades (**A+** to **F**).
- **OLED Pure Black Theme:** `#000000` AMOLED mode to conserve battery on OLED displays and eliminate glow on OLED TVs.
- **Wi-Fi Diagnostics & Band Detection:** Real-time link speed (e.g. 866 Mbps) and frequency band (2.4 GHz, 5 GHz, 6 GHz Wi-Fi 6E/7).
- **History CSV Export:** Export past speed test measurements to CSV spreadsheet format.
- **TV Remote Navigation:** Full D-Pad (Up, Down, Left, Right, Enter/OK, Back) support across all TV interfaces.
