# Pulse Speed v1.5.2 — Seamless Android Update & Multiplatform

## 🚀 Critical Android Update Fix

### 📱 Official Release Key Signing (Fixed "האפליקציה לא עודכנה" / "App Not Installed")
- **Cause:** When updating from `v1.4.0`, Android's Package Manager verifies that the incoming APK signature matches the installed APK's certificate. Because previous intermediate builds were compiled with debug signatures, Android rejected the update with an "App not updated" error.
- **Fix:** `Pulse-v1.5.2.apk` is signed with the official `CN=Pulse, O=dor2500` release keystore (`SHA-256: 75beab5036c6ca2b91a4dc3a2b60da852e1f63df361d8059e3da938158ef69de`), with `versionCode = 8` and `versionName = "1.5.2"`.
- **Result:** Existing users on `v1.4.0` can now seamlessly update either via the in-app updater (Settings → Updates) or by directly downloading and tapping `Pulse-v1.5.2.apk` with zero errors.
