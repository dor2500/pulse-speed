**Choose your test server**

- **Server picker**, just like Speedtest: tap the new **Server** row under the source chips.
  - **Ookla**: the nearest speedtest.net servers with provider, city and distance; search any city or provider worldwide (e.g. "Haifa", "Bezeq").
  - **LibreSpeed**: every community server, sorted by measured ping.
  - **FAST**: the Netflix servers assigned to your connection.
  - **Automatic** stays the default and picks the fastest nearby server.
- Each server shows a live ping badge so you can see which one is closest.
- Your choice is remembered per source, and history records which server each test used.
- Cloudflare always routes you to its nearest data center, so it has no picker.

**Install:** open Settings → Updates in the app, or download `Pulse-v1.6.0.apk` below.

**בחירת שרת לבדיקה**

- **בחירת שרת**, כמו ב-Speedtest: הקישו על השורה החדשה **שרת** מתחת לצ׳יפים של המקורות.
  - **Ookla**: השרתים הקרובים של speedtest.net עם ספק, עיר ומרחק; אפשר לחפש כל עיר או ספק בעולם (למשל "Haifa", ‏"Bezeq").
  - **LibreSpeed**: כל שרתי הקהילה, ממוינים לפי הפינג שנמדד.
  - **FAST**: שרתי Netflix שמוקצים לחיבור שלכם.
  - **אוטומטי** נשאר ברירת המחדל ובוחר את השרת הקרוב והמהיר.
- ליד כל שרת מוצג פינג חי, כדי לראות מי הכי קרוב.
- הבחירה נשמרת לכל מקור בנפרד, ובהיסטוריה מופיע מול איזה שרת נמדדה כל בדיקה.
- ‏Cloudflare תמיד מנתבת למרכז הנתונים הקרוב, ולכן אין בה בחירת שרת.
