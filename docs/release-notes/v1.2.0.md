**In-app updates and a language switch**

- **Updates button** in Settings: checks GitHub for a new version, downloads the APK with a progress bar and opens the installer. Pulse also checks quietly at launch and puts a dot on the Settings tab when an update is waiting.
- **Language switch** in Settings: System, English or עברית, applied instantly.
- The first time you update from inside the app, Android asks once to allow Pulse to install apps. After that, updates are one tap.

**Install:** download `Pulse-v1.2.0.apk` below. It updates earlier versions in place and keeps your history. From this version on, future updates can be installed from inside the app.
