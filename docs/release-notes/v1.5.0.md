**Universal Multiplatform Release: Stremio, LG TV, Samsung TV, Kodi, Linux, Windows, Mac & Android TV**

### Universal Platform Coverage:
- **Stremio Community Addon (`Pulse-v1.5.0-stremio-addon.zip`)**:
  - Run speed tests directly inside Stremio (`stremio://` protocol support, catalog, and streaming endpoints).
- **Samsung Smart TV (`Pulse-v1.5.0-tizen.wgt`)**:
  - Samsung Tizen WGT widget package for Samsung Smart TVs with full remote control support.
- **LG webOS Smart TV (`Pulse-v1.5.0-webos.ipk`)**:
  - LG Smart TV `.ipk` package with D-Pad navigation and Magic Remote cursor support.
- **Android TV & Google TV & Amazon Fire TV (`Pulse-v1.5.0.apk`)**:
  - Full Android TV Leanback launcher banner and D-Pad focus navigation.
- **Kodi Media Center (`Pulse-v1.5.0-kodi-addon.zip`)**:
  - Kodi Python addon (`plugin.program.pulsespeed`) with live speed progress dialogs and results.
- **Linux (`pulse_1.5.0_all.deb` & `Pulse-v1.5.0-linux.tar.gz`)**:
  - Native `.deb` package for Ubuntu, Debian, Mint & Raspberry Pi, plus universal tarball.
- **Windows Desktop (`Pulse.exe` & `Pulse-v1.5.0-windows.zip`)**:
  - Standalone portable desktop executable (90 KB).
- **macOS Desktop (`Pulse-v1.5.0-mac.zip`)**:
  - Standalone `Pulse.app` bundle for Mac.
- **Universal CLI Tool (`pulse-cli.py`)**:
  - Zero-dependency command-line speed tester for terminals, servers & headless systems.
- **Web (`Pulse-v1.5.0-web.zip`)**:
  - Responsive HTML5/CSS/JS client for any browser.

### What's New in the Engine:
- **Bufferbloat / Loaded Latency Engine**:
  - Measures ping under load during both download and upload.
  - Automatically calculates your Bufferbloat grade (**A+**, **A**, **B**, **C**, **D**, **F**).
- **OLED Pure Black Theme**:
  - Adds a true pitch-black AMOLED/OLED mode (`#000000`).
- **Wi-Fi Diagnostics**:
  - Displays Wi-Fi link speed (e.g. `866 Mbps`) and frequency band (`2.4 GHz`, `5 GHz`, `6 GHz Wi-Fi 6E/7`).
- **History Export to CSV**:
  - Export test history into CSV spreadsheet format.
