**Multiplatform Release: Bufferbloat, OLED Pure Black, LG webOS TV, Windows EXE & Mac**

### What's New in v1.5.0:
- **Bufferbloat / Loaded Latency Engine**:
  - Measures real ping under load during both download and upload.
  - Automatically calculates your Bufferbloat grade (**A+**, **A**, **B**, **C**, **D**, **F**) to diagnose latency spikes during gaming, streaming, or video calls.
- **OLED Pure Black Theme**:
  - Adds a true pitch-black AMOLED/OLED mode (`#000000`), reducing power consumption and providing infinite contrast on OLED smartphones and LG OLED TVs.
- **Wi-Fi & Connection Diagnostics**:
  - Displays Wi-Fi link speed (e.g. `866 Mbps`) and frequency band (`2.4 GHz`, `5 GHz`, `6 GHz Wi-Fi 6E/7`).
- **History Export to CSV**:
  - Export your entire speed test history into CSV format for easy charting and network reliability analysis.

### Multiplatform Expansion:
- **LG webOS Smart TV (`Pulse-v1.5.0-webos.ipk`)**:
  - Fully compatible with LG webOS Smart TVs.
  - Full TV remote control D-Pad navigation (Arrow keys, Enter, Back button `461`) and Magic Remote cursor support.
  - 10-foot UI optimized for 1080p and 4K TV screens.
- **Windows Desktop (`Pulse.exe` / `Pulse-v1.5.0-windows.zip`)**:
  - Standalone, ultra-lightweight (90 KB) desktop executable with embedded speed test engine, window framing, and custom icon.
- **macOS Desktop (`Pulse-v1.5.0-mac.zip`)**:
  - Standalone `Pulse.app` bundle for macOS.
- **Web Package (`Pulse-v1.5.0-web.zip`)**:
  - Responsive web version for browser deployment.
