First release of **Pulse**, a Material You speed test for Android.

- Ping, jitter, download and upload against the Cloudflare speed test network
- Live gauge, speed-over-time graph and result sharing
- History with averages and bests
- Dynamic color on Android 12+, light and dark themes
- English and Hebrew (RTL)

**Install:** download `Pulse-v1.0.0.apk` below and open it on your phone. You may need to allow installs from your browser or file manager. Requires Android 8.0+.
