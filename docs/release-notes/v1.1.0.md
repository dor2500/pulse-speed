**Material 3 Expressive redesign**

- Floating pill navigation bar; the active tab shows its label inside a horizontal pill
- New morphing gauge: an organic four-petal shape that breathes and reacts to live speed, with progress drawn on an organic ring
- When the test finishes, the shape morphs into a capsule showing the final result
- Asymmetric rounded cards; the card for the running phase springs larger and lifts
- Speed graph in an elevated, softly rounded container
- Filled pill "Test again" button and outlined "Share" button
- Haptic feedback when a test completes

**Install:** download `Pulse-v1.1.0.apk` below. It updates v1.0.0 in place and keeps your history.
