- **Google sign-in is back.** Versions 1.9.2 to 1.10.0 were built without the Firebase configuration, so the account card (sign-in and cloud sync) disappeared from Settings. Your synced history is still in the cloud and comes back as soon as you sign in.
- Release builds now stop if the Firebase configuration is missing, so this can't ship again.

**Install:** open Settings → Updates in the app, or download `Pulse-v1.10.1.apk` below.
