**Four test networks and a Stop button**

- **Choose where to test**, right above the gauge:
  - **Cloudflare**: global edge network, nearest data center
  - **Ookla**: the speedtest.net server network; Pulse probes the nearest servers and uses the fastest
  - **FAST**: Netflix's servers, the same ones FAST.com uses
  - **LibreSpeed**: open-source community servers; the fastest-responding one is picked
- **Stop test**: a large red pill button while a test runs. It closes every connection at once and nothing from the stopped run is saved.
- History now shows which network and server each result came from.

Ookla and FAST are used through the same public endpoints their own websites call. They aren't official APIs, so either one may change or stop working without notice.

**Install:** open Settings → Updates in the app, or download `Pulse-v1.4.0.apk` below.

**ארבע רשתות בדיקה וכפתור עצירה**

- **בחירה מול מה לבדוק**, ממש מעל המד:
  - **Cloudflare**: הרשת הגלובלית, מרכז הנתונים הקרוב
  - **Ookla**: רשת השרתים של speedtest.net; ‏Pulse בודקת את השרתים הקרובים ובוחרת את המהיר
  - **FAST**: השרתים של Netflix, אותם שרתים ש-FAST.com משתמש בהם
  - **LibreSpeed**: שרתי קהילה בקוד פתוח; נבחר זה שעונה הכי מהר
- **עצירת הבדיקה**: כפתור גלולה אדום וגדול בזמן בדיקה. הוא סוגר מיד את כל החיבורים, ושום דבר מהבדיקה שנעצרה לא נשמר.
- בהיסטוריה מופיע עכשיו מול איזו רשת ואיזה שרת נמדדה כל תוצאה.

Ookla ו-FAST נבדקים דרך אותן כתובות ציבוריות שהאתרים שלהם עצמם משתמשים בהן. אלה לא ממשקים רשמיים, ולכן הם עלולים להשתנות או להפסיק לעבוד בלי התראה.
